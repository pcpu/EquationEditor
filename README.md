# EquationEditor

一个可视化、可交互的网页版数学公式编辑器（接近 MathType / AxMath 的交互体验），支持：

- 可视化交互编辑数学公式
- 公式实时导出为 LaTeX
- 将 LaTeX 导入回可交互编辑器继续编辑
- KaTeX 实时渲染预览
- 常用结构工具栏（分数、根号、上下标、求和、积分、极限、矩阵等）

## 技术方案

- **MathLive**：负责“可交互数学编辑内核”（光标、选区、结构输入、撤销重做、数学键盘等）。
- **KaTeX**：负责渲染预览，验证 LaTeX 的可渲染性。
- **原生 HTML/CSS/JS**：实现编辑器外壳、工具栏、状态管理和双向转换控制。

## 使用方法

> 由于依赖浏览器 ES Module，建议通过本地 HTTP 服务运行。

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173
```

## 交互说明

1. 在左侧编辑区直接输入/编辑公式（可视化编辑）。
2. 右侧 LaTeX 文本框会实时同步导出结果。
3. 右侧可手动修改/粘贴 LaTeX，点击“导入到可视化编辑区”即可转换为可编辑公式。
4. 支持撤销、重做、复制 LaTeX、虚拟数学键盘显示/隐藏。

## 文件结构

- `index.html`: 页面结构与控件。
- `styles.css`: 页面样式。
- `main.js`: 编辑器逻辑（双向转换、工具栏交互、预览渲染、状态更新）。
